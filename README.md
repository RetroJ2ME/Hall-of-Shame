# Hall of Shame

重新打包他人成果，以雞鳴狗盜、慷他人之慨的行為散布，並非理所應當。

使用開源成果的同時，也應履行相應的授權義務。

本 Repository 用以記錄 [RetroJ2ME](https://github.com/RetroJ2ME) 中經查證且在通知後仍未解決的違規散布行為。


## 收錄範圍

主要查核與 RetroJ2ME 專案有關的以下問題，實際義務以涉及版本的授權條款為準：

- 重新散布時，移除應保留的著作權、授權或免責聲明，或未向接收者提供適用的授權條款全文。
- 散布包含 GPLv3 程式碼或資產的預編譯 JAR，卻未依條款提供完整對應原始碼，或提供的來源與實際散布版本不符。
- 散布修改版，卻未依適用條款標示修改資訊。
- 使用 RetroJ2ME 的開源授權散布第三方遊戲內容，但該內容的再散布並未獲得相應授權；此類個案須另列權利歸屬與查核依據。

GPLv3 允許依條款修改、重新散布及收費；這些行為本身不構成列名理由。單純私人使用或修改，也不要求向公眾公開原始碼。

相關許可規定見[第 2、4、5、6、10 節](https://www.gnu.org/licenses/gpl-3.0.html)。封裝程式的授權與第三方遊戲內容的授權須分別確認。


## 記錄

紀錄採用[個案範本](templates/case.md)，存放於 `cases/YYYY/README.md`。


## 回報

請在本 Repository 打開一個新的 issue，選擇對應範本：

- [散布問題回報](.github/ISSUE_TEMPLATE/report.md)：提供散布頁面、涉及專案、版本、查核日期與具體疑點；
- [補正與更正](.github/ISSUE_TEMPLATE/correction.md)：提出補正結果、授權證明、歸屬異議或查核錯誤，若有相關個案，請直接在對應 Issue 下討論。

Issue 與附件均為公開。

證據請使用必要的文字摘錄、已遮蔽私人資料的截圖及檔案 SHA-256，引用散布頁面時，請移除網址中的個人識別資訊、存取權杖與私人邀請碼等內容。
